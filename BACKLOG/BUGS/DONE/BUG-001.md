# BUG-001: Favicon onglet affiche une feuille générique au lieu du logo

**Type:** Bug
**Statut:** A faire
**Priorite:** Haute
**Complexite:** XS
**Tags:** favicon, branding
**Depends on:** none
**Blocked by:** —
**Date creation:** 2026-03-27

---

## Description

L'icône de l'onglet navigateur affiche une feuille verte générique ronde au lieu du logo Art des Jardins (feuille de marronnier + rameaux dorés).

### Cause racine

Le commit `af012ce` a régressé les fichiers `favicon.ico` et `apple-touch-icon.png` en restaurant les versions génériques. Le commit précédent `d4f2cc6` contenait les bonnes versions (favicon.ico = vrai ICO multi-résolution 5.2KB, apple-touch-icon.png = logo correct 23KB).

Les fichiers `icon-32.png` et `icon-192.png` sont corrects mais le navigateur charge `favicon.ico` en priorité.

## Fichiers concernes
- `public/favicon.ico` — actuellement PNG 1.1KB (feuille générique), doit être restauré depuis commit d4f2cc6 (ICO 5.2KB)
- `public/apple-touch-icon.png` — actuellement 6KB (feuille générique), doit être restauré depuis commit d4f2cc6 (23KB)

## Approche recommandee

```bash
git checkout d4f2cc6 -- public/favicon.ico public/apple-touch-icon.png
```

Restaurer les deux fichiers depuis le commit qui avait les bonnes versions.

## Criteres d'acceptation
- [ ] `favicon.ico` est un vrai fichier ICO multi-résolution (16x16 + 32x32), ~5KB
- [ ] `apple-touch-icon.png` affiche le logo Art des Jardins (feuille marronnier + rameaux dorés), ~23KB
- [ ] L'onglet navigateur affiche le bon logo après hard refresh (Cmd+Shift+R)

## Tests de validation
- [ ] `file public/favicon.ico` → doit indiquer "MS Windows icon resource"
- [ ] `wc -c public/favicon.ico` → ~5265 bytes
- [ ] `wc -c public/apple-touch-icon.png` → ~23041 bytes
- [ ] Ouvrir le site en navigation privée → l'onglet montre le logo Art des Jardins
