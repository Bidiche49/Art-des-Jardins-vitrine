# BUG-003: Lightbox galerie — ESC natif desynchronise le state React

**Type:** Bug
**Statut:** A faire
**Priorite:** Haute
**Complexite:** XS
**Tags:** ux, galerie
**Depends on:** none
**Blocked by:** —
**Date creation:** 2026-03-28

---

## Description

Le `<dialog>` natif de la lightbox (PhotoGallery) se ferme via Escape par son comportement par defaut, mais `lightboxIndex` reste non-null dans le state React. Le `useEffect` detecte `lightboxIndex !== null` et rappelle `showModal()`, rouvrant immediatement le dialog.

En parallele, un listener `window.keydown` appelle aussi `closeLightbox()` sur Escape, creant un race condition avec l'evenement natif du dialog.

## Cause racine

Le composant ne synchronise pas le state React avec l'evenement `close` natif du `<dialog>`.

## Fichiers concernes
- `src/components/ui/PhotoGallery.tsx` — composant lightbox galerie

## Approche recommandee

1. Ajouter `onClose={closeLightbox}` sur l'element `<dialog>` pour synchroniser le state quand le dialog se ferme nativement
2. Supprimer le handler `Escape` dans le listener `window.keydown` (le dialog natif gere deja Escape, le `onClose` synchronisera le state)
3. Conserver les handlers `ArrowLeft` / `ArrowRight` dans le listener window

## Criteres d'acceptation
- [ ] Appuyer Escape ferme la lightbox definitivement (pas de reouverture flash)
- [ ] Les fleches gauche/droite naviguent toujours entre les photos
- [ ] Cliquer sur le backdrop ferme la lightbox
- [ ] Cliquer sur le bouton fermer ferme la lightbox
