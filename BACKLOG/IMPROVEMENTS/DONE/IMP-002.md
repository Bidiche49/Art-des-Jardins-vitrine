## Description

Les numeros de telephone, l'adresse, l'email et le lien WhatsApp sont hardcodes en literals dans 19+ fichiers. Un changement de numero requiert 19 modifications manuelles avec risque eleve d'oubli et d'incoherence.

## Fichiers concernes
- `src/lib/site-config.ts` — **a creer** : source unique des donnees de contact
- `src/components/layout/Header.tsx` — telephone dans le CTA header
- `src/components/layout/Footer.tsx` — telephone, email, adresse
- `src/components/ui/MobileStickyBar.tsx` — telephone dans le lien
- `src/components/ui/WhatsAppButton.tsx` — numero WhatsApp
- `src/components/HomeFAQ.tsx` — telephone dans les reponses FAQ
- `src/components/ContactForm.tsx` — eventuels numeros dans les messages
- `src/app/contact/page.tsx` — telephone, email, adresse, lien Maps
- `src/app/layout.tsx` — metadata (URL du site)
- `src/components/seo/LocalBusinessSchema.tsx` — telephone, email, adresse
- `src/components/seo/LocalBusinessCitySchema.tsx` — telephone, email, adresse
- `src/components/seo/ServiceSchema.tsx` — telephone, email, adresse
- Pages service/ville (si telephone mentionne)

## Approche recommandee

1. Creer `src/lib/site-config.ts` exportant un objet `SITE_CONTACT` :
   ```ts
   export const SITE_CONTACT = {
     phone1: '07 81 16 07 37',
     phone1Link: 'tel:+33781160737',
     phone1International: '+33781160737',
     phone2: '06 59 68 49 16',
     phone2Link: 'tel:+33659684916',
     email: 'contact@artdesjardins-paysagiste.fr',
     whatsapp: '33781160737',
     address: {
       street: '9 bis rue Rouget de l\'Isle',
       city: 'Les Ponts-de-Ce',
       postalCode: '49130',
       region: 'Maine-et-Loire',
       country: 'FR',
     },
     siteUrl: 'https://artdesjardins-paysagiste.fr',
     companyName: 'Art des Jardins',
   };
   ```
2. Rechercher toutes les occurrences avec grep (07 81, 06 59, contact@, 9 bis, artdesjardins)
3. Remplacer par des imports depuis site-config.ts
4. Verifier avec grep qu'aucun literal ne subsiste
