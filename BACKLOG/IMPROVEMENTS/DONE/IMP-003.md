## Description

Deux duplications majeures identifiees :

1. **Liste des villes** : la homepage (`page.tsx:225-243`) hardcode 17 villes inline alors que `cities-data.ts` est la source autoritaire pour `generateStaticParams`. Les deux listes peuvent diverger.

2. **Liste des services** : la homepage (`page.tsx:283-322`) definit un `const services[]` local avec 6 entrees. Le Header (`Header.tsx:19-58`) definit `serviceMenuItems[]` separe. `services/page.tsx` derive sa liste de `services-data.ts`. Trois sources pour le meme catalogue.

3. **Slugs credit d'impot** : le tableau `['entretien-jardin', 'taille-haies', 'debroussaillage']` est hardcode identiquement dans `services/page.tsx:58` et `services/[slug]/page.tsx:166`.

## Fichiers concernes
- `src/lib/services-data.ts` — ajouter `cardDescription` et `isTaxCreditEligible` si necessaire, exporter `TAX_CREDIT_SLUGS`
- `src/lib/cities-data.ts` — source autoritaire (deja en place)
- `src/app/page.tsx` — supprimer `const services[]` local + inline cities, importer depuis les sources
- `src/components/layout/Header.tsx` — supprimer `serviceMenuItems[]`, deriver depuis services-data
- `src/app/services/page.tsx` — importer `TAX_CREDIT_SLUGS`
- `src/app/services/[slug]/page.tsx` — importer `TAX_CREDIT_SLUGS`

## Approche recommandee

### Villes (page.tsx)
- Importer `cities` depuis `@/lib/cities-data`
- Mapper : `cities.map(c => ({ name: c.name, href: \`/paysagiste-\${c.slug}/\` }))`
- Supprimer le tableau inline

### Services (page.tsx + Header.tsx)
- Verifier si `services-data.ts` a deja les champs necessaires (slug, shortTitle, description courte)
- Si manquant, ajouter un champ `cardDescription` au type `ServiceData`
- Exporter une liste ordonnee ou un helper depuis services-data.ts
- page.tsx et Header.tsx importent et mappent

### Credit d'impot
- Ajouter un champ `isTaxCreditEligible: boolean` dans `ServiceData` ou exporter `TAX_CREDIT_SLUGS`
- Importer dans les deux pages services
