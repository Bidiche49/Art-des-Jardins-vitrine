## Description

Trois lacunes d'accessibilite identifiees par l'audit :

1. **Pas de skip link** — les utilisateurs clavier doivent tabber a travers toute la navigation (header sticky + mega-menu) sur chaque page
2. **Pas de focus management dans la lightbox** — `showModal()` n'est suivi d'aucun `focus()`, le focus reste en dehors du dialog, le focus trap natif n'est pas engage. Pas d'`aria-label` sur le dialog.
3. **Boutons filtres galerie sans `aria-pressed`** — l'etat actif est visuel uniquement, invisible pour les screen readers

## Fichiers concernes
- `src/app/layout.tsx` — ajout du skip link + `id="main-content"` sur `<main>`
- `src/components/ui/PhotoGallery.tsx` — focus management lightbox + aria-pressed sur filtres

## Approche recommandee

### Skip link (layout.tsx)
- Ajouter `<a href="#main-content" className="sr-only focus:not-sr-only focus:absolute focus:top-4 focus:left-4 focus:z-50 focus:bg-white focus:px-4 focus:py-2 focus:rounded focus:shadow-lg">Aller au contenu principal</a>` en premier enfant du `<body>`
- Ajouter `id="main-content"` sur l'element `<main>`

### Focus management lightbox (PhotoGallery.tsx)
- Apres `dialogRef.current?.showModal()`, appeler `focus()` sur le bouton fermer (ajouter une ref sur le bouton)
- Ajouter `aria-label="Visionneuse photo"` sur le `<dialog>`

### aria-pressed filtres (PhotoGallery.tsx)
- Ajouter `aria-pressed={activeCategory === null}` sur le bouton "Tout"
- Ajouter `aria-pressed={activeCategory === cat}` sur chaque bouton categorie
