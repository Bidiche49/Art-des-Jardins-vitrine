## Description

Le script `scripts/optimize-images.mjs` n'a aucun test. La fonction `generateManifest()` est une pure function (recoit un tableau de resultats, retourne une string TypeScript) facilement testable sans mock.

Identifie lors de l'audit BUG-002 (boy scout rule).

## Fichiers concernes
- `scripts/optimize-images.mjs` — source a tester (fonction `generateManifest` lignes 198-230)
- `scripts/optimize-images.test.mjs` — **a creer** : tests unitaires

## Approche recommandee

1. Creer `scripts/optimize-images.test.mjs` (ou `.test.js` selon la config vitest)
2. Tester `generateManifest()` avec :
   - Input nominal : tableau de 2-3 resultats valides → verifier que le manifest TypeScript genere est syntaxiquement correct
   - Input vide : tableau vide → verifier le comportement (manifest vide ou erreur)
   - Input avec tags et alt contenant des apostrophes → verifier l'echappement
3. Pour rendre `generateManifest` testable, il faudra peut-etre l'exporter. Si le script est un ESM monolithique, extraire la fonction dans un module separe ou utiliser un export conditionnel.
