## Description

Le composant PhotoGallery n'a aucun test. Il contient une logique interactive non triviale : ouverture/fermeture lightbox via dialog natif, navigation clavier (fleches), filtres par categorie, synchronisation state React avec le dialog natif.

Identifie lors du fix BUG-003 (boy scout rule).

## Fichiers concernes
- `src/components/ui/PhotoGallery.tsx` — composant a tester
- `src/components/ui/__tests__/PhotoGallery.test.tsx` — **a creer**

## Approche recommandee

Tests avec @testing-library/react + jsdom :
1. Ouverture lightbox au clic sur une image → dialog visible
2. Fermeture via Escape → dialog ferme, lightboxIndex reset (verifie le fix BUG-003)
3. Navigation fleches gauche/droite → image change
4. Clic backdrop → fermeture
5. Filtres categorie → images filtrees correctement

Prerequis : vitest.config.ts doit exister (voir IMP-006 ou creer le config si absent).
