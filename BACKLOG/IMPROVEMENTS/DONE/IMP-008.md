## Description

Les OG images actuelles sont de simples photos sans branding. Quand le lien est partagé sur les réseaux sociaux / WhatsApp, aucun logo ni nom d'entreprise n'apparaît sur la preview.

Modifier `generateOGImages()` dans `scripts/optimize-images.mjs` pour ajouter un overlay brandé sur chaque OG image :
- Photo de fond (1200x630, crop cover — existant)
- Gradient sombre en bas (~35-40% de la hauteur)
- Logo `logo-leaf.png` (feuille marronnier + rameaux dorés)
- Texte "Art des Jardins" en titre
- Sous-titre adapté par image (ex: "Paysagiste à Angers", "Élagage Angers", etc.)

## Fichiers concernes
- `scripts/optimize-images.mjs` — modifier `generateOGImages()` pour compositer l'overlay via sharp
- `public/images/og-image.jpg` — régénéré (et les 4 autres OG images)
- `public/images/logo-leaf.png` — lu comme source pour le logo (217x120, RGBA, transparent)

## Approche recommandee

Utiliser l'API `sharp.composite()` avec un SVG overlay pour le gradient + texte, et `logo-leaf.png` comme image composite séparée.

```javascript
// Pseudo-code de l'approche
const photo = sharp(inputPath)
  .rotate()
  .resize(1200, 630, { fit: 'cover', position: 'center' });

const svgOverlay = `<svg width="1200" height="630">
  <defs>
    <linearGradient id="grad" x1="0" y1="0.55" x2="0" y2="1">
      <stop offset="0%" stop-color="rgba(0,0,0,0)" />
      <stop offset="100%" stop-color="rgba(0,0,0,0.65)" />
    </linearGradient>
  </defs>
  <rect width="1200" height="630" fill="url(#grad)" />
  <text x="600" y="540" text-anchor="middle" fill="white"
        font-family="Arial, Helvetica, sans-serif" font-size="48" font-weight="bold">
    Art des Jardins
  </text>
  <text x="600" y="585" text-anchor="middle" fill="rgba(255,255,255,0.85)"
        font-family="Arial, Helvetica, sans-serif" font-size="28">
    Paysagiste à Angers
  </text>
</svg>`;

// Logo-leaf centré au-dessus du texte
const logoBuffer = await sharp('public/images/logo-leaf.png')
  .resize(100, null)  // ~100px wide
  .toBuffer();

await photo
  .composite([
    { input: Buffer.from(svgOverlay), top: 0, left: 0 },
    { input: logoBuffer, top: 440, left: 550, gravity: 'center' },
  ])
  .jpeg({ quality: 85 })
  .toFile(outputPath);
```

**Points d'attention :**
- Le positionnement exact du logo et du texte devra être ajusté visuellement
- Utiliser des polices sans-serif de base (Arial/Helvetica) pour la compatibilité CI/CD
- Le sous-titre doit varier par image OG (ajouter un champ `subtitle` dans `OG_IMAGES`)
- Le logo-leaf a un fond transparent → il se composera proprement sur l'overlay sombre
