# IMP-009: Le summary OG affiche le nombre total au lieu du nombre réellement généré

**Type:** Improvement
**Statut:** A faire
**Priorite:** Basse
**Complexite:** XS
**Tags:** build, DX
**Depends on:** none
**Blocked by:** —
**Date creation:** 2026-03-28

---

## Description

Dans `scripts/optimize-images.mjs`, la ligne summary `console.log(\`${OG_IMAGES.length} OG images generated\`)` affiche toujours le nombre d'entrées dans le tableau OG_IMAGES (5), même si certaines sources sont absentes et que l'image n'a pas été générée. Devrait compter les images effectivement générées.

## Fichiers concernes
- `scripts/optimize-images.mjs` — compteur dans `generateOGImages()` + summary dans `main()`

## Criteres d'acceptation
- [ ] Le summary affiche le nombre d'OG images réellement générées (ex: "3 OG images generated" si 2 sources manquent)

## Tests de validation
- [ ] `pnpm images:optimize` avec sources partiellement absentes → le compte est correct
