## Description

Le badge crédit d'impôt utilise deux styles d'apostrophe selon le contexte :
- Homepage (page.tsx) : `'Crédit d'impôt 50 %'` (apostrophe droite ASCII `'`)
- Header (Header.tsx) : `'Crédit d\u2019impôt'` (apostrophe typographique `'`)

Harmoniser vers l'apostrophe typographique (`\u2019`) partout — c'est la norme typographique française.

## Fichiers concernes
- `src/app/page.tsx` — badge dans le mapping services homepage
- `src/components/layout/Header.tsx` — badge dans le mapping services header

## Criteres d'acceptation
- [ ] Toutes les occurrences de "Crédit d'impôt" utilisent `\u2019` (apostrophe typographique)
- [ ] `pnpm build` passe sans erreur

## Tests de validation
- [ ] `grep -rn "Crédit d'" src/` — toutes les occurrences utilisent le même caractère
