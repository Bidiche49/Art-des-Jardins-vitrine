## Description

`services-data.ts` est maintenant la source unique pour les services (homepage, header, pages services, crédit d'impôt). Un champ vide ou manquant casserait silencieusement le rendu. Des tests d'intégrité valideraient que chaque service a tous les champs requis non vides.

Identifié lors du fix IMP-003 (boy scout rule).

## Fichiers concernes
- `src/lib/services-data.ts` — source à tester
- `src/lib/__tests__/services-data.test.ts` — **à créer**
