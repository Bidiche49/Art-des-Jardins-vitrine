# IMP-015: Refactorer le template [serviceCity] — supprimer le boilerplate, exploiter le contenu unique

**Type:** Improvement
**Statut:** A faire
**Priorite:** Haute
**Complexite:** M
**Tags:** seo, template, ui, cities
**Depends on:** IMP-013, IMP-014
**Blocked by:** IMP-014
**Date creation:** 2026-03-28

---

## Description

Le template `[serviceCity]/page.tsx` affiche actuellement ~75% de contenu identique entre les 80 pages (features grid, "pourquoi choisir", CTA). Ce boilerplate est un signal doorway pour Google. Apres le remplissage du contenu unique (IMP-014), le template doit etre refactore pour maximiser la part de contenu unique et minimiser le boilerplate.

## Cause racine

Le template a ete concu avec un seul `specificContent` par ville. Avec le nouveau `serviceContent`, la structure de la page doit evoluer pour donner plus de place au contenu unique et supprimer les sections generiques identiques.

## Approche recommandee

### Sections a MODIFIER :

1. **H2 principal** : remplacer `{Service} professionnel a {Ville}` par un titre redige unique (ajouter un champ `h2` optionnel dans `ServiceCityContent`, fallback sur le template actuel)

2. **Features grid ("Nos prestations")** : utiliser les `highlights` du `serviceContent` au lieu du `features` generique du `ServiceCityData`. Les highlights sont contextualises (sol, terrain, conditions locales). Fallback sur `features` si pas de highlights.

3. **Section "Pourquoi choisir Art des Jardins"** :
   - Remplacer les 4 cards identiques par des arguments contextualises
   - Au minimum : varier le texte "Proximite" selon la distance reelle, et "Experience" selon le type de travaux courants dans cette commune
   - Option : supprimer cette section sur les pages villes (la garder uniquement sur les pages hub Angers)

4. **CTA final** : varier le texte. Pas "Contactez Art des Jardins pour un devis gratuit" sur 80 pages — utiliser le contexte local ("Votre jardin a {ville} merite un expert du terrain {type_sol}")

### Sections a SUPPRIMER ou DEPLACER :

5. **Grille "Communes voisines"** : la garder mais la rendre moins proeminente (pas un H2). Voir IMP-016 pour le tri par proximite.

### Sections a AJOUTER :

6. **Lien retour vers la page hub Angers** clairement visible (breadcrumb existe deja, mais ajouter un lien contextuel dans le contenu : "Decouvrez l'ensemble de nos prestations d'elagage")

## Fichiers concernes

- `src/app/[serviceCity]/page.tsx` — refactoring du template
- `src/lib/cities-data.ts` — ajout eventuel du champ `h2` dans `ServiceCityContent` (si le worker le juge pertinent)
