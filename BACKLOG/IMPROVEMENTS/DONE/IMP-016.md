## Description

La section "Communes voisines" en bas des pages service x ville affiche les 10 premieres villes de l'array `cities`, quel que soit la ville courante. Une ville en fin d'array (ex: Soulaines-sur-Aubance) voit toujours Angers, Avrille, Beaucouze... comme "voisines", meme si elles sont a 15 km.

Pour un meilleur signal SEO local et une meilleure UX, les communes affichees doivent etre triees par proximite geographique reelle par rapport a la ville courante.

## Approche recommandee

1. **Ajouter des coordonnees GPS a chaque `CityData`** :
   ```typescript
   geo?: { lat: number; lng: number };
   ```

2. **Fonction de tri par distance** :
   ```typescript
   function sortByProximity(cities: CityData[], from: CityData): CityData[] {
     return cities
       .filter(c => c.slug !== from.slug)
       .sort((a, b) => haversine(from.geo, a.geo) - haversine(from.geo, b.geo));
   }
   ```

3. **Utiliser ce tri** dans `[serviceCity]/page.tsx` et dans les 4 pages Angers dediees pour la section communes voisines.
