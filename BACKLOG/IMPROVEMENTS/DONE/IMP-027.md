## Approche technique

- Les images sont deja en WebP, 1024x1536 (~1.3MB chacune). Elles seront affichees a ~300-400px de large max. Utiliser `<img>` natif avec `width`/`height` explicites, `loading="lazy"`, `decoding="async"`, et un `max-width` CSS pour que le navigateur gere le scaling.
- Pas besoin de passer par le pipeline `optimize-images.mjs` ni `images-manifest.ts` — ces portraits ne font pas partie de la galerie de realisations.
- Layout : grid 2 colonnes desktop (md:grid-cols-2), 1 colonne mobile. Chaque carte : photo (rounded, object-cover, crop haut du portrait), nom en H3, description en paragraphes.
- Respecter le design system existant : classes `container-custom`, couleurs `text-gray-600`, `text-gray-900`, espacements `py-16 lg:py-24`.
