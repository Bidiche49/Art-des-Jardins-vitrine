## Description

Deuxième batch du service **abattage** dans la wave 2. Ajouter les champs `accroche` et `whyPro` dans `serviceContent.abattage` pour les 4 villes du batch B2 :

- Trélazé
- Les Ponts-de-Cé
- Écouflant
- Cantenay-Épinard

Chaque paire `accroche` + `whyPro` doit être unique par ville, strictement tirée du `serviceContent.abattage.content` existant, et respecter le ton abattage (déclaratif, technique, sécurité/réglementation/dessouchage).

**Règle critique** — traçabilité **au niveau de la phrase**, pas du fait global. Interdiction d'ajouter un mécanisme, une cause, un seuil ou une démonstration technique absent du `.content`.

**Référence** : le batch B1 (IMP-046) est committé — le worker doit s'y référer comme standard de ton/structure.
