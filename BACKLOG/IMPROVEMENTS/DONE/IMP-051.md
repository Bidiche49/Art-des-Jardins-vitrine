## Description

PageSpeed Insights signale **767 Kio d'économies** sur les images et des décalages CLS dus à l'absence de `width`/`height`. Les principaux coupables :

1. `BeforeAfterSlider` sert du **800w hardcodé** sans `srcset`, alors qu'affiché 665px max (et ~350px mobile). 6 images concernées sur home → ~467 Kio récupérables.
2. `PhotoGallery` utilise déjà `<picture srcset>` ✅ mais les `<img>` n'ont pas de `width`/`height` → CLS reporté.
3. Images gallery 480w surdimensionnées pour leur cellule masonry (266×355 affiché).

Les variantes 480w/800w/1200w/1920w existent déjà dans `public/images/realisations/` et `images-manifest.ts`. Il suffit de les consommer correctement.

## Fichiers concernes

- `src/components/ui/BeforeAfterSlider.tsx` — remplacer `<img>` bruts par `<picture>` + `srcset` via `getSrcSet`/`getImage`, ajouter `width`/`height`. Changer la signature pour accepter un `slug` au lieu d'une URL brute (ou accepter les deux).
- `src/components/BeforeAfterSection.tsx` — adapter la liste `projects` pour passer les slugs au slider.
- `src/components/ui/PhotoGallery.tsx` — ajouter `width={image.sizes[480].width}` `height={image.sizes[480].height}` sur le `<img>` du grid (ligne 123).
- `src/components/ui/StatsCounter.tsx` — `<img>` 1200w en décoration, à remplacer par `<picture srcset>` avec sizes adapté (ou supprimer si purement décoratif et remplacer par gradient).
