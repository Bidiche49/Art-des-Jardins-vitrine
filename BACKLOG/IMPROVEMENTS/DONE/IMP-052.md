## Description

Deux sujets :

1. **Logo `logo-leaf.png` 30 Kio en PNG 217×120** alors qu'affiché 89×49 dans la nav. Conversion WebP + redimensionnement 180×100 → ~3 Kio (gain 27 Kio, impact FCP mobile).
2. **LCP avec 1980 ms de "délai d'affichage"** sur la hero (`entretien-2-800w.webp`) — l'image est chargée (fetchpriority=high + preload) mais quelque chose retarde le paint. Suspects : overlay absolu, hydration de `HeroClient`, animation CSS, ou `min-h-[calc(100vh-4rem)]` qui bloque le layout tant que les polices chargent.

Le point 2 est le plus impactant sur le score mobile. Nécessite investigation avant de coder.

## Fichiers concernes

- `public/images/logo-leaf.png` — à remplacer par `logo-leaf.webp` redimensionné
- `src/components/layout/Header.tsx` (ou équivalent nav) — update src vers `.webp`, ajouter `width={90} height={50}`
- `src/components/ui/HeroSection.tsx` — investiguer pourquoi `HeroClient` est client component (peut-il devenir server ?)
- `src/components/ui/HeroClient.tsx` — potentiellement supprimable si rien de client-only ne reste
- `src/app/globals.css` ou équivalent — vérifier animations/transitions sur `.hero-section`
