## Description

Sur mobile, l'affichage des galeries de photos est actuellement un scroll vertical d'images les unes sous les autres. C'est fonctionnel mais peu moderne et fait paraître les pages très longues.

Objectif : repenser le pattern d'affichage des photos sur mobile (carrousel swipe-able, grille 2 colonnes avec lightbox, masonry, ou autre approche moderne) tout en gardant l'expérience desktop existante (ou en l'améliorant en cohérence).

**Important** : à exécuter dans une **nouvelle conversation** avec le skill `frontend-design` pour avoir une approche design robuste qui évite les patterns AI génériques.

**Périmètre exhaustif** : ce ticket concerne TOUS les endroits où des galeries d'images sont affichées, pour garder une cohérence visuelle dans le site.

## Fichiers concernes
