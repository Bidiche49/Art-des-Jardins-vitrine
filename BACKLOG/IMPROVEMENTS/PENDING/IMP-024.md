## Description

`pnpm lint` (qui appelle `next lint`) ne fonctionne pas car aucun fichier de configuration ESLint n'existe dans le projet. La commande déclenche un setup interactif au lieu de linter. Le quality gate lint est donc inopérant depuis la création du projet.

## Fichiers concernes
- `.eslintrc.json` (ou `eslint.config.mjs`) — a créer
- `package.json` — potentiellement ajouter des dépendances ESLint

## Criteres d'acceptation
- [ ] `pnpm lint` s'exécute sans interaction et retourne 0 warning/0 error
- [ ] Configuration cohérente avec Next.js 14 + TypeScript

## Tests de validation
- [ ] `pnpm lint` — doit passer sans erreur ni prompt interactif
