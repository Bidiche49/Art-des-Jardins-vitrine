## Description

La page 404 actuelle (générée par Next.js par défaut ou minimaliste) ne respecte pas la charte graphique du site. Quand un visiteur tombe sur une URL inexistante, il sort visuellement de l'expérience.

Objectif : avoir une page 404 cohérente avec le reste du site (header + footer normaux du site, palette primary/secondary, fonts Inter + Cormorant Garamond), avec un message clair et un CTA vers la home.

## Fichiers concernes

- `src/app/not-found.tsx` — fichier à créer (convention Next.js App Router pour les 404)
- `src/components/layout/Header.tsx` — header existant à réutiliser
- `src/components/layout/Footer.tsx` — footer existant à réutiliser
- `tailwind.config.js` — couleurs primary/secondary à réutiliser

## Criteres d'acceptation

- [ ] Page accessible via une URL inexistante (ex: `/page-inexistante`) qui affiche un message 404
- [ ] Header du site affiché en haut (logo + navigation)
- [ ] Footer du site affiché en bas (NAP + liens)
- [ ] Message 404 clair en français : titre + texte court explicatif
- [ ] CTA visible vers la home (bouton style primary)
- [ ] CTA secondaire vers la page contact ou les services principaux
- [ ] Typographie cohérente (Cormorant Garamond pour le titre, Inter pour le texte)
- [ ] Responsive mobile/desktop
- [ ] Status HTTP 404 correctement renvoyé (Next.js le gère via `not-found.tsx`)

## Tests de validation

- [ ] `curl -I https://artdesjardins-paysagiste.fr/page-inexistante/` retourne `HTTP/2 404`
- [ ] Visite manuelle d'une URL inexistante en navigateur : la page affiche header + message + CTA + footer
- [ ] Test responsive mobile (DevTools 375px) : pas de débordement, CTA tappable
- [ ] Vérifier que `next build` génère bien la page 404 dans `out/`
